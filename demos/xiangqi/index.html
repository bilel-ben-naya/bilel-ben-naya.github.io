Xiangqi, échecs chinois sur 11 x 11

Mon jeu Java réécrit pour le navigateur : mêmes règles, même bot. Les Rouges commencent. Cliquez sur une pièce puis sur une case en surbrillance.

Historique

Ce que ce port reproduit. Le moteur (déplacements de chaque pièce, échec, mat, pat, généraux face à face) et le bot (score par capture, avancée des soldats, mobilité, menaces, protection du général, pénalité de risque) sont repris du code Java. Je les ai comparés au Java sur plus de 2 200 positions de parties aléatoires : mêmes coups possibles, mêmes états d'échec et même coup choisi par le bot.

Les règles sont celles du projet, pas celles du Xiangqi officiel : plateau de 11 x 11 avec la rivière sur une ligne entière, cases autorisées pour les éléphants et déplacements du cheval propres au projet.
