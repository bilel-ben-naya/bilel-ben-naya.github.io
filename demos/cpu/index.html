Simulateur d'ordonnancement de processus

Les quatre algorithmes du projet C (FIFO, SJF, SJRF, Round Robin) portés en JavaScript. Modifiez les processus, choisissez un algorithme et regardez le CPU les exécuter milliseconde par milliseconde.

Type E/S : 0 aucune, 1 parallèle (le CPU est libéré), 2 non parallèle (le CPU est bloqué). Les lignes qui commencent par # sont ignorées.

Comparaison

D'où viennent les calculs. Chaque algorithme reprend la logique du code C final du groupe (horloge de 1 ms, E/S déclenchée après un certain temps de CPU, formules de métriques identiques). Le port a été comparé au programme C sur des centaines de jeux de processus tirés au hasard, avec des résultats identiques. Le temps d'attente vaut restitution moins CPU moins E/S.

Deux limites du programme C d'origine, conservées ici : l'E/S ne peut pas se déclencher à la dernière milliseconde de CPU (le début E/S doit être inférieur à la durée CPU), et Round Robin peut ne jamais terminer si un processus arrive pendant une E/S non parallèle. Dans ces cas la démo l'indique au lieu de se figer.
