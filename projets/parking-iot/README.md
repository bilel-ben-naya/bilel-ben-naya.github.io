# Parking connecté intelligent

Projet d'Internet des Objets (Cergy Paris Université, 2025-2026).
Dania Hamitouche, Imane Moussaoui, Odessa Triollet-Pereira, Alexis Sade, Bilel Ben Naya.

- `codes_parking_2` : programme final de l'Arduino Mega (3 places à ultrasons, barrière à servomoteur, LED, Ethernet, Blynk). Le jeton Blynk a été retiré : renseigner le sien dans `BLYNK_AUTH_TOKEN`.
- `arduino` : essais intermédiaires (un, deux, trois capteurs, moteur, Ethernet).
- `backend` : serveur FastAPI avec base SQLite (places, sessions, tarification à la minute).

Dépôt d'origine de l'équipe : https://github.com/imn-ms/ConnectedParking
Démo dans le navigateur : https://bilel-ben-naya.github.io/demos/parking/index.html
