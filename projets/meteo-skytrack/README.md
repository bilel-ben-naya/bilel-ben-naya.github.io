# SkyTrack, site météo

Site de prévisions météo pour les communes de France (PHP, HTML, CSS, JavaScript), réalisé à deux avec Alexis Sade dans le module Développement Web.
Les clés d'API ont été retirées : renseigner les siennes dans `index.php`, `tech.php` et `include/functions.inc.php` (chercher `VOTRE_`).

Démo dans le navigateur (version JavaScript de la page de prévisions) : https://bilel-ben-naya.github.io/demos/meteo/index.html
