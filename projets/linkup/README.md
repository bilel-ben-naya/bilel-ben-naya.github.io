# LinkUp

Application Android (Java) d'événements : formulaire d'accueil enregistré dans les préférences, base SQLite, liste des événements, import depuis un fichier téléchargé par un service, carte avec la position GPS.

L'image `doakes.jpg` de l'écran d'accueil n'est pas incluse dans ce dépôt (ajouter une image de votre choix sous ce nom dans `app/src/main/res/drawable`).

Aperçu dans le navigateur : https://bilel-ben-naya.github.io/demos/linkup/index.html
